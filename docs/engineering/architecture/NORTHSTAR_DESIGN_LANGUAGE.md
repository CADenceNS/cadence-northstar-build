## NSDL visual system

- Pure-black, low-glare working canvas with obsidian application framing.
- Command rail and modular workspace framing; avoid conventional business-app sidebar presentation.
- Frosted information surfaces, technical HUD/telemetry components, and restrained approximately 200 ms interaction motion.
- Accent language: Cyber Cyan, Bio-Green, Electric Violet, and Warning Amber.
- Design Studio entry remains a separate CAD/CAM boundary and uses high-contrast, neon CAD-state presentation; this document does not authorize changes to Design Studio geometry or dental algorithms.

## Explicit exclusions

Do not use a generic white SaaS dashboard, accounting-style interface, Sprint-era shipping form presentation, old UAT shell, or any Keramos identity as a NorthStar owner-facing visual baseline. Existing backend workflows, authentication, tenant isolation, Platform Admin boundaries, CSRF, cookies, commercial licensing, entitlement, and seat semantics remain independent from this visual authority.
